# Week 7 Assignment: My Notes & The Report Builder

- `my_notes.py` — Writes three notes, appends a fourth note, reads the notes, and counts the total lines.
- `my_notes.txt` — The notes file generated by `my_notes.py`.
- `report_builder.py` — Reads learner scores from `hubs.csv`, calculates the total, passed count, failed count, and average score, then writes `report.txt`.
- `hubs.csv` — Contains the learner names, hubs, and scores used by the report builder.
- `report.txt` — The report generated by `report_builder.py`.

If `"a"` were changed to `"w"` in Question 1, Python would erase the existing notes before writing, so only the newly written notes would remain in `my_notes.txt`.
